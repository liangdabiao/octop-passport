# Assets

Everything the firmware embeds beyond code. This app ships **fonts only** — there are no audio
assets (effects and the two background-music loops are RTTTL-synthesized at runtime, see
`main/sb_sfx.c`) and no bitmap images (the bridge map is drawn from widgets, see
`main/sb_ui.c`).

| File | What it is | Provenance |
| --- | --- | --- |
| [`fonts/charset.txt`](fonts/charset.txt) | The derived character inventory, one comment header plus the codepoints | Generated by `tools/seven-bridges/gen_font.py`; never edit |
| [`fonts/op_font_16.c`](fonts/op_font_16.c) | 16 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |
| [`fonts/op_font_24.c`](fonts/op_font_24.c) | 24 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |
| [`fonts/op_font_32.c`](fonts/op_font_32.c) | 32 px LVGL font subset | Generated; Noto Sans CJK SC, SIL OFL 1.1 |

## How the inventory is derived

`tools/seven-bridges/gen_font.py` unions two sources, so the fonts can never drift from the
interface strings: the non-ASCII characters of every string literal under `main/` (comments
stripped first; baseline demo sources are excluded — they are not built into the firmware),
and a fixed base of printable ASCII plus the punctuation and star glyphs (★☆) the UI uses.
Before converting, every codepoint is checked against the master font's cmap — a missing
glyph is a build failure, not a hollow box on the device.

`gen_font.py --check` re-derives the inventory and re-parses the generated `.c` files (their
sparse cmap tables) to assert every codepoint is really present; `tools/validate.sh` runs it in
the static gate.

## The master font

Noto Sans CJK SC Regular, SHA-256
`2c76254f6fc379fddfce0a7e84fb5385bb135d3e399294f6eeb6680d0365b74b`,
SIL Open Font License 1.1 — a licence that permits subsetting and redistribution inside the
firmware. See `tools/seven-bridges/gen_font.py` for the download URL and the conversion command.

## No content pipeline

Unlike the quiz/ladder siblings of this family, Seven Bridges has **no external level bank and
no content table**: the twelve levels are hand-crafted graphs in `main/sb_level.c`, and their
graph-theoretic facts (parity, solvability, the finale's demolish-any-bridge property) are
pinned by `tests/test_sb_level.c` on the host. Audio is two RTTTL loops plus ten short tones,
all synthesized in `main/sb_sfx.c`.
